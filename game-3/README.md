# The Beginning of Crazy Animals

A mobile-friendly Flappy Bird-style game built with Phaser 3. Pilot a rocket through gaps in
asteroid fields — tap, click, or press Space to fire the thruster.

Playable on phones, tablets, and desktop: the canvas scales to fit any screen in portrait, and
any tap/click/Space flaps.

## Run

```bash
bun install
bun run dev
```

Then open the printed `localhost:5173` URL. To test on a phone, open the LAN URL Vite prints
(both devices on the same Wi-Fi).

## Build

```bash
bun run build
```

## How to play

- **Tap / click / Space** — fire the thruster to rise
- Dodge the asteroid clusters; clearing a field scores a point
- Hitting a rock, the top, or the bottom ends the run
- High score is saved locally in your browser
